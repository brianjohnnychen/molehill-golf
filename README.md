# Molehill Golf Co.

Demo storefront for an original junior golf equipment brand: club sets sized by height, soft-strike foam balls, big tees, practice gear and a trade-up program. Mascot: Divot, a mole who lives under the 18th green.

Single static page (`index.html`) with inline CSS/SVG and a small vanilla-JS size finder. Fonts are self-hosted in `fonts/` (Lilita One and Nunito, both SIL Open Font License, see the OFL files there).

## Deploy

GitHub Pages serves the `main` branch root. Push to `main` and the site updates in about a minute.

Live: https://brianjohnnychen.github.io/molehill-golf/
